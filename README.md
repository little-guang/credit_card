# 信用卡違約分析

本專題使用台灣信用卡客戶資料，分析客戶的人口特徵、信用額度、繳款紀錄與帳單金額，並探討哪些因素可能與信用卡違約有關。

## 資料來源

資料來自 UCI Machine Learning Repository：

- [Default of Credit Card Clients](https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients)
- 資料集名稱：Default of Credit Card Clients
- 資料筆數：30,000 筆
- 目標欄位：`default_payment_next_month`
- 目標欄位意義：客戶是否在下個月違約，`1` 代表違約，`0` 代表未違約

## 專題目標

1. 了解信用卡客戶資料的結構與分布情形。
2. 探索信用額度、年齡、教育程度、婚姻狀況及繳款紀錄等變數與違約的關係。
3. 分析不同客戶群體的違約率差異。
4. 找出可能有助於信用風險評估的關鍵特徵。
5. 建立可延伸至違約預測模型的乾淨資料集。

## 預計分析內容

### 1. 資料清理

- 檢查資料型別、缺失值與重複資料。
- 整理欄位名稱，使其適合在 Python 與 SQL 中使用。
- 確認客戶識別欄位 `ID` 的唯一性。
- 檢查類別變數與數值變數的內容是否合理。

### 2. 探索式資料分析

- 計算整體違約率。
- 比較不同信用額度、年齡、教育程度與婚姻狀況的違約率。
- 分析過去數月的繳款狀態與違約之間的關係。
- 比較帳單金額、繳款金額與違約情形的差異。
- 使用表格與圖表整理分析結果。

### 3. SQL 分析

- 建立原始資料表與清理後資料表。
- 撰寫查詢統計各類客戶的違約人數與違約率。
- 依信用額度、年齡及繳款狀況進行分組比較。
- 彙整可供報告使用的分析結果。

### 4. 後續延伸

- 將違約欄位作為分類模型的預測目標。
- 比較邏輯斯迴歸、決策樹或其他分類方法的表現。
- 使用適當的評估指標，例如準確率、精確率、召回率與 ROC-AUC。

## 資料欄位概述

資料包含客戶基本資料、信用額度、過去六個月的帳單金額、過去六個月的繳款金額，以及過去六個月的繳款狀態。主要欄位與可能出現的資料內容如下：

| 欄位 | 說明 | 可能的資料內容 |
| --- | --- | --- |
| `ID` | 客戶識別碼 | 整數，每位客戶應具有唯一值 |
| `LIMIT_BAL` | 信用額度 | 數值，通常以新台幣表示，例如 `50000`、`200000` |
| `SEX` | 性別 | `1`：男性；`2`：女性 |
| `EDUCATION` | 教育程度 | `1`：研究所；`2`：大學；`3`：高中；`4`：其他；`0`、`5`、`6`：未明確分類或其他類別 |
| `MARRIAGE` | 婚姻狀況 | `1`：已婚；`2`：單身；`3`：其他；`0`：未明確分類 |
| `AGE` | 年齡 | 整數，例如 `21`、`35`、`60` |
| `PAY_0` | 2005 年 9 月繳款狀態 | `-2`：該期無消費；`-1`：當期繳清；`0`：使用循環信用；`1` 至 `8`：延遲 1 至 8 個月；`9`：延遲 9 個月以上 |
| `PAY_2` 至 `PAY_6` | 2005 年 8 月至 2005 年 4 月的繳款狀態 | 編碼意義與 `PAY_0` 相同 |
| `BILL_AMT1` 至 `BILL_AMT6` | 過去各月份的帳單金額 | 數值，例如 `0`、`12000`、`-500`；欄位尾碼代表不同月份 |
| `PAY_AMT1` 至 `PAY_AMT6` | 過去各月份的繳款金額 | 數值，例如 `0`、`2000`、`15000`；欄位尾碼代表不同月份 |
| `default_payment_next_month` | 下個月是否違約 | `0`：未違約；`1`：違約 |

### 繳款狀態欄位補充

`PAY_0` 至 `PAY_6` 的數值代表相對於應繳日期的繳款狀態：

| 編碼 | 意義 |
| --- | --- |
| `-2` | 該期沒有消費，因此沒有需要繳款的金額 |
| `-1` | 當期已繳清 |
| `0` | 使用循環信用，或沒有延遲繳款 |
| `1` 至 `8` | 延遲 1 至 8 個月 |
| `9` | 延遲 9 個月以上 |

實際分析前仍應使用程式檢查各欄位的唯一值與分布，因為資料中的特殊編碼可能需要依研究目的重新分類或清理。

## 執行資料轉換

請先準備資料來源提供的 Excel 檔案，並將檔名設為 `default of credit card clients.xls`，放在專案根目錄。接著執行：

```bash
python convert.py
```

執行後會產生 `credit_card.csv`，並在終端機顯示資料筆數、欄位名稱、缺失值與重複的 `ID` 數量。
